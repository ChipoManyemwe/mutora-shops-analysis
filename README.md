# Why Did Mutora Shops Close?

## Overview

A Power BI case study analyzing historical bookkeeping records from **Mutora General Dealer & Bottle Store (2010–2015)**.

The project explores:

- Goods cost
- Potential sales value
- Cash collected
- Expected earnings
- Inventory movement
- Operating costs and losses

## Key Findings

| Metric | Value |
|---|---:|
| Goods Cost | 33K |
| Potential Sales Value | 52K |
| Cash Collected | 33K |
| Expected Earnings | 15K |
| Cash Collection Rate | 64.1% |
| Sales Gap | 18K |

The analysis identifies a significant gap between potential sales value and recorded cash collection, highlighting **cash realization and inventory movement as areas for further investigation**.

The data does not establish a single definitive cause of closure.

## Data Note

The analysis uses reconstructed historical bookkeeping records. Some records represent stock movements, balances, or accounting adjustments rather than direct sales transactions. Currency denomination is not consistently specified, so monetary values are shown without a currency symbol.

**Analysis Period:** 2010–2015
